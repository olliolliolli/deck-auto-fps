# AutoFPS — Decky Loader плагін

Автоматично підбирає **стабільний** FPS для кожної гри і за потреби вмикає фрейм-генерацію.

| Пристрій | Рівні FPS | Частота екрана |
|---|---|---|
| Steam Deck LCD | 30 / 40 / 60 | перемикається (40–60 Гц) під рівень |
| Steam Deck OLED | 30 / 40 / 45 / 60 / 90 | перемикається (45–90 Гц), напр. 40 FPS → 80 Гц |
| Lenovo Legion Go S | 30 / 40 / 60 / 120 | лишається 120 Гц (усі рівні діляться рівно) |

## Як працює

1. Гра стартує через обгортку → вмикається невидимий лог MangoHud.
2. **Розігрів** 20 с (завантаження, компіляція шейдерів не враховуються).
3. **Вимірювання** 20 с без ліміту. Береться p10 — FPS, нижче якого лише 10% часу.
4. Обирається найвищий рівень, який p10 тримає із запасом (за замовчуванням 95%).
5. Якщо до верхнього рівня не дотягує, а база ≥ 40 FPS — вмикається **lsfg-vk ×2**
   (напр. Legion Go S: 60 → 120; OLED: 45 → 90).
6. Далі **моніторинг** кожні 10 с: просідання двічі поспіль → рівень нижче;
   GPU завантажений < 55% протягом хвилини → повторне вимірювання вгору.
7. Результат запам'ятовується для гри — наступного разу без вимірювання.

## Встановлення

1. Завантажте `AutoFPS.zip` зі сторінки
   [Releases → latest](https://github.com/olliolliolli/deck-auto-fps/releases/tag/latest)
   (збирається автоматично при кожній зміні в `main`; або вручну: `bash build.sh`).
2. Decky → ⚙ → увімкнути **Developer Mode** → Developer → **Install Plugin from Zip**.
3. Для фрейм-генерації: купити **Lossless Scaling** у Steam і встановити плагін
   **Decky LSFG-VK** з магазину Decky → у ньому натиснути *Install lsfg-vk*.
   AutoFPS використовує встановлений шар, але свій окремий конфіг
   (`~/.config/autofps/lsfg-vk.toml`), тож налаштування не конфліктують.
4. Для кожної гри: Властивості → Параметри запуску:
   ```
   bash ~/homebrew/plugins/AutoFPS/bin/autofps %command%
   ```
   Не поєднуйте з `~/lsfg %command%` — обгортка AutoFPS уже вмикає lsfg-vk.
5. У швидкому меню Steam (…) → Продуктивність **вимкніть ліміт кадрів** Steam.

## Автоналаштування графіки гри (як оптимізація NVIDIA)

Плагін сам визначає рушій гри і підбирає графіку **за кілька запусків**:

| Рушій | Що змінюється | Де |
|---|---|---|
| Unreal Engine 4/5 | 11 груп `sg.*` (тіні, GI, відображення, пост-обробка…) + роздільна здатність | `GameUserSettings.ini` у префіксі Proton |
| Unity (Proton) | рівень якості Unity + роздільна здатність | `user.reg` у префіксі (PlayerPrefs) |
| Unity (Linux-версія) | те саме | `~/.config/unity3d/<Компанія>/<Гра>/prefs` |

**Як іде підбір.** Якість розкладено на «сходинки» (Unreal — 12, Unity — до 10):
спершу знижується те, що дає найбільше FPS за найменшу втрату картинки
(тіні, глобальне освітлення, відображення, об'ємні ефекти), роздільна здатність
і текстури — наприкінці.

1. Перший запуск: ставиться стартова сходинка під пристрій, плагін міряє p10 FPS.
2. Наступний запуск: не тягне ціль — нижче на 1–3 сходинки (залежно від нестачі);
   запас понад 25% — якість вище; в межах норми — **готово**, налаштування фіксуються.
3. Якщо зміна на 2+ сходинки не змінила FPS — гра впирається в процесор або
   ігнорує файл; плагін припиняє підбір і більше нічого не чіпає.

Ціль якості за замовчуванням: Deck LCD — 40, Deck OLED — 45, Legion Go S — 60 FPS
(фрейм-генерація далі доводить до 90/120). Змінюється в меню плагіна.

**Безпека.** Файли змінюються лише перед запуском гри, коли вона їх не тримає.
Перший оригінал зберігається як `*.autofps.bak`, кнопка «Повернути оригінальні
налаштування» відновлює їх при наступному запуску.

**Важливо:** файл налаштувань з'являється після першого запуску гри — зіграйте
раз і вийдіть через меню. Ігри зі своєю системою налаштувань (не `sg.*` / не
PlayerPrefs) підбір розпізнає як «не впливає» і залишить у спокої.

### Ручні профілі

Для ігор на інших рушіях — `~/.config/autofps/profiles/<AppID>.json`
(приклад у `profiles/EXAMPLE_unreal.json`). Ручний профіль має пріоритет над автопідбором.

## Обмеження та чесні застереження

- Перевірено логіку на симуляції (зокрема хеші ключів Unity і сходження підбору), а не на залізі — перший запуск дивіться в
  `~/homebrew/logs/AutoFPS/` і `~/.cache/autofps/wrapper.log`.
- Ліміт FPS і частота ставляться через атоми gamescope (`GAMESCOPE_FPS_LIMIT`,
  `GAMESCOPE_DYNAMIC_REFRESH`). Якщо Steam перебиває — плагін повторює кожні 5 с.
- lsfg-vk: конфіг у форматі v1 (стабільна гілка). Для dev-збірок 2.x формат може відрізнятися.
- Якщо MangoHud рахує FPS до фрейм-генерації, вимкніть `fps_counts_generated`
  у `~/.config/autofps/settings.json`.
- TDP плагін не чіпає — для цього є SimpleDeckyTDP / вбудований слайдер.
